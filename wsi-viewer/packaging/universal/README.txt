WSI Hive — runs from this USB / drive (no install, no web download to use)
============================================================================

1) Open **Start Here.html** for the full user guide, screenshots, security-warning help, and launch links.
2) Put your whole-slide files in the **Slides** folder in the **root** of this folder (next to the three “WSI-Hive” starters for Windows, Mac, and Linux).
3) Double-click **your** platform’s file only: **WSI-Hive-Windows.bat** (PC), **WSI-Hive-macOS.command** (Mac), or **WSI-Hive-Linux.sh** (Linux, may need to run in a terminal the first time). The Electron app and platform builds live under **.wsi-usb/** — that engine folder is automatically hidden in Explorer (Windows) or in Finder (Mac) after a successful first launch, so the root of the drive looks simple.
4) You do not need to download WSI Hive from the internet to run it. You already have it.

A small hidden folder “.wsi-hive-data” may appear on the **drive** next to the app — that is settings/cache kept on the device.

See FLASH_DRIVE.md in the project (developer notes) for full details.
